# Jevでプロジェクトの記述を分類する試作

2026-09-21実施。既存の `public/data/videos.json.bak` から目的別に20本を選び、タイトル・概要欄114区間を実際のJev APIで分類した。動画本文の字幕は今回取得できていない。元データは2006年〜2025年4月、419件・動画ID重複除去後410本。現在の動画公開状態は未確認。

## 実測結果

- モデル: `jev-1.13.0`（固定）
- 20本の分類: 26リクエスト、入力75,138トークン、従量料金換算 **$0.003155796**。
- 一括／個別比較: 7リクエスト、入力3,203トークン。
- 上記合計: 33リクエスト、入力78,341トークン、**$0.003290322**。
- 別に接続確認を1回実行: 入力300トークン、$0.0000126。すべてを合わせると **$0.003302922**。
- 同じタイトルへの6つのトピック質問: 個別2,504トークン → 一括699トークン、**72.1%削減**。判定値は完全一致ではないが、この例の0.8/0.2の振り分けは変わらなかった。
- 原文から事前に設定した10項目（計画、試作完成、改良済み、手戻りなど）は10項目一致。意図的な少数例であり、全体の正答率・再現率を意味しない。

料金は [公式モデル説明](https://docs.typesafe.ai/models) の入力100万トークン$0.042、出力無料で換算した値。請求書や最低購入額は確認していない。字幕取得、文字起こし、別のLLMの費用は含まない。

## 分かったこと

- 「STV2ProtoType完成」と、同じ概要欄の「今後調整して楽器を録音したい」を別の記述として保持できた。
- シグナルジェネレーターでは「改良方法が見つかったら直す」と「ピンクノイズを改良できた」の両方を保持できた。前者だけで未完了と判定してはいけない。
- 完成例だけでなく、ゲーム配信のタイトルを製作完了に分類しない確認も行った。
- **プロジェクトの名寄せはまだ弱い。** ガードリング動画の関連判定は0.58、STV2の仕様検討などは0.57〜0.62となった。0.8で除外すると必要な動画が消えるため、画面は0.5以上を候補とし0.8未満を要確認と明示する。これらの閾値は未校正。
- 関連性はバッチごとの最大値で集約している。最大値は校正済みの動画単位の確率ではない。長い概要欄には関係の薄い宣伝文もあるため、次段では根拠区間ごとのプロジェクト対応を評価する。
- 記述は「当該資料にそう書かれている」ことの候補。現在の状態、出来事の日付、プロジェクト全体の完成、続報なし、未完了は判定していない。

## 再実行

Node.js 22以上。依存パッケージの追加は不要。

認証は環境変数 `TYPESAFE_API_KEY`、またはリポジトリ直下の `.env` を利用する。`.env` はGit対象外、今回のローカルファイルの権限は600。キーを `public/` やソースコードに置かない。

```bash
node --env-file=.env scripts/runJevPilot.js --compare
python3 -m http.server 8766 --bind 127.0.0.1 --directory .local/jev-pilot
```

ブラウザで `http://127.0.0.1:8766/report.html` を開く。結果は `.local/jev-pilot/report.json` と `report.html`。APIへの送信・応答は `cache/`、実行ごとの使用量と失敗状況は `runs/` に保存する。公開用フォルダには書き込まない。

同じ字幕・質問・モデルの結果はキャッシュを利用し、再課金を避ける。キャッシュだけで再実行する場合はキー不要。HTMLの「今回のAPI呼び出し」は0になり、「分類結果の入力従量費用」には既存結果を得た費用が残る。新しい出力ディレクトリはキャッシュを共有しない。

`--limit 1〜20`、`--budget 0.10`（USD）、`--input 動画JSON`、`--output 出力ディレクトリ` を指定できる。現段階では試作用の20動画IDを選ぶため、任意チャンネルの全件処理用ではない。

予算チェックはUTF-8バイト数に余裕を加えた保守的な入力トークン見積もりを累積して送信前に検査する。プロバイダー側の請求上限ではない。自動再試行はせず、通信失敗は課金状態不明として台帳に残す。既定予算は一実行$0.10、CLIで許す上限は$1。HTTPエラー本文・認証ヘッダはログに出さず、リダイレクトを拒否する。

## 字幕を加える

公開YouTubeページの字幕エクスポートを `w6mhMfC2vLE` と `LhcPZzKHE8Y` で試したが、この取得経路では利用可能な字幕が返らなかった。字幕が存在しないと断定するものではない。次に所有者のYouTube Studioから字幕を取得するか、所有者OAuthで公式字幕APIの取得可否を調べる。手元の音声があれば文字起こしも候補。

SRT/VTTファイルがある場合:

```bash
node scripts/importJevSubtitles.js --input /path/to/subtitles.srt --video LhcPZzKHE8Y
node --env-file=.env scripts/runJevPilot.js --transcripts .local/jev-transcripts
```

字幕は `.local/jev-transcripts/<videoId>.json` に変換される。形式は `[{"start":0,"end":5,"text":"実際の字幕"}]`、時刻は秒。字幕がある動画は字幕を分類し、ない動画はタイトル・概要欄へフォールバックして画面に区別を表示する。原文の時刻を保持しYouTubeの該当位置へリンクする。

SRT/VTTの表示装飾は除去する。ローリング自動字幕の重複整理、映像だけで示された作業の理解、字幕誤認識の修正はまだ行わない。字幕での実行費用・精度は未測定。
